# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.5.x   | :white_check_mark: |
| < 0.5   | :x:                |

## Reporting a Vulnerability

Please do not open a public issue for a vulnerability.
Report it privately with [GitHub private vulnerability reporting](https://github.com/Pop-Code/nestjs-authentication/security/advisories/new)
(**Security** tab → **Report a vulnerability**).
If the report is accepted, we will publish a fix and an advisory.
