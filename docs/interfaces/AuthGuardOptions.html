    OptionalexceptionFactory

    exceptionFactory?: AuthExceptionFactory

    Creates the error thrown when a required request is not authenticated. If not set, the guard returns false and NestJS throws a 403 Forbidden. Use unauthorized for a 401.

    required?: boolean

    strategies

    strategies: { [strategyName: string]: AuthenticateOptions }

    The passport strategies to try, in order, with their authenticate options. The first one that authenticates the request wins. Defaults: authInfo: true, session: false (set session: true to store the user in the session).
