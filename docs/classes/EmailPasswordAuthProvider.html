    Class EmailPasswordAuthProvider<User>

    The auth provider of the users who log in with an email and a password. Your users keep their shape: give the functions that find and read them.

    new EmailPasswordAuthProvider<UserEntity>({
        encryptor,
        findById: (id) => users.findOneBy({ id }),
        findByEmail: (email) => users.findOneBy({ email }),
        getId: (user) => user.id,
        getPasswordHash: (user) => user.passwordHash
    });
    • login ({ email, password }): findByEmail(), then checks the password against the hash with the encryptor (and stores a new hash with updatePasswordHash() if the encryptor says it needs a rehash)
    • session or token payload ({ sub, namespace }): findById()
    • the payload of a user is { sub: getId(user), namespace }
