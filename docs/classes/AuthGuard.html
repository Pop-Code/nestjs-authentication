    Class AuthGuard

    Authenticates the requests with the strategies, on every transport (http, GraphQL, websockets, microservices), and checks the required scopes.

    Use it in two ways:

    • global (registered by the AuthModule): configure the routes with Auth, Public, RequireScopes, and the defaults / globalGuard options of the module
    • per route: @UseGuards(new AuthGuard({ strategies: { jwt: {} }, required: true }))

    On success, the user is set in request.user, the auth info of each strategy in request.authInfo[strategyName], and the AuthContext is available with CurrentUser, CurrentAuth and the AuthContextService.
