    Class AuthGuard

    A guard that authenticates the request with one or more passport strategies.

    Works with http (express, fastify), GraphQL (queries, mutations, subscriptions), websockets (socket.io, ws) and microservices: the AuthTransport of the context gives the request to passport.

    On success, the user is set in request.user, the auth info of each strategy in request.authInfo[strategyName], and the AuthContext is available with CurrentUser, CurrentAuth and the AuthContextService.

    @UseGuards(new AuthGuard({ strategies: { emailpassword: { session: true } }, required: true }))
