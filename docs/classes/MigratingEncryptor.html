    Class MigratingEncryptor

    Migrates the stored passwords to a new encryptor, one user at a time, on login:

    • new passwords are encrypted with current
    • a stored value is checked with the first encryptor that can verify it (canVerify()), current first
    • needsRehash() is true for the values of the legacy encryptors (and the ones current wants to rehash), so AuthMemoryUserProvider stores the password again with current after a successful login (if the user provider implements updatePassword())
    AuthModule.forRoot({
        encrypt: { key, iv }, // the legacy aes-256-ctr encryptor
        encryptor: new MigratingEncryptor(new ScryptEncryptor(), [new Encryptor({ key, iv })])
    });
