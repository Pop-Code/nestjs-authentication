    Class AuthModule

    The authentication module (global).

    • forRoot() / forRootAsync(): configures the module once, in the root module

    • registerAuthProviders(): registers the auth providers (one per namespace)

    • registerStrategies(): registers your own strategies (AuthStrategy)

    It provides the AuthService, the AuthContextService, the AuthStrategyRegistry with the emailpassword, session and (when configured) jwt strategies, the ENCRYPTOR (and the default Encryptor) and the AuthScopes, and registers the global AuthGuard and AuthContextInterceptor.
